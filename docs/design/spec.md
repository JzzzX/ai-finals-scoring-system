# 视觉规格

依据用户确认的清爽布局及后续修订：原始品牌 logo、深蓝与姜黄碰撞、评分改为滑块与输入框。

- 主蓝 #183B70；深正文 #10274A；姜黄 #E7B347；浅黄 #FFF5DB；白色 #FFFFFF；页面 #F4F6FA；边框 #DDE4EF。
- 系统中文字体 PingFang SC / Microsoft YaHei，正文 16px、辅助 14px，手机标题 26px、桌面标题 30px；数字等宽。
- 桌面顶部原始品牌组合标识、身份、退出；侧边队列约 320px；白色主工作区，32px 内间距。
- 手机顶部品牌独占一行，标题/身份第二行；队伍列表为抽屉；评分参考默认折叠；底部固定提交区域预留安全间距。
- 评分控件：一个 range 与一个 number input，均为 0–10 / step 0.5，空值不预填，未选分时隐藏滑块圆点并明确文字说明；第一次点击或键盘操作后才形成草稿。
- 管理台姜黄选中导航、深蓝动作按钮、白色表格。手机展示完整队伍名称与汇总列表，展开单队评分详情；完整矩阵允许在独立区域水平滚动。
- 图片中分数只是布局示意，正式数据库不导入示例评分。六维度正文以 rev232 原文为准，修正图片生成的错字和改写。品牌使用用户提供的原始文件，不用效果图重绘版本。
- 三张生成效果图由内置 imagegen 生成。非核心登录、成员与赛事设置页面沿用相同设计组件。

记录的必要差异：显示真实登录人姓名；页面保留赛事名称；说明和状态来自实际数据；原始品牌资产保留全部内容；新增错误/离线/冲突提示用于真实交互。
